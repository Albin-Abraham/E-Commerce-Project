# 🔤 Typography

Typography is a foundational design primitive that defines how written information is **structured, prioritized, measured, displayed, and experienced** across the product.

Typography establishes the visual language used by every layer of the system—from primitive text values to semantic text styles, components, patterns, and product interfaces.

Components such as `Text`, `Button`, `Input`, `Card`, `Navigation`, `Table`, and `Heading` should consume typography tokens and semantic text styles rather than introducing arbitrary font properties.

> **Typography should communicate hierarchy, meaning, and readability before decoration.**

# 02 — Typography Principles

### 01. Hierarchy over decoration
Typography should establish hierarchy through size, weight, spacing, and structure before relying on decorative styling.

### 02. Consistency over arbitrary values
A component should never introduce:
```css
font-size: 17px;
font-weight: 550;
```
unless those values are intentionally part of the system.
Prefer:
```ts
text.body.md
```

### 03. Semantic meaning over visual appearance
Prefer:
```ts
text.heading.2
```
rather than:
```ts
text.large.bold
```
The first describes **purpose**; the second describes appearance.

### 04. Content determines layout
Text is dynamic. Components must accommodate:
- Longer text
- Multiple lines
- Localization and expansion
- Text scaling
- User-generated content

### 05. Readability before density
The goal is not to fit the maximum amount of text into the minimum amount of space.

### 06. Accessibility is foundational
Accessibility should not be a component-level afterthought.

# 03 — Font Families

## Primary UI Family
The primary family is used throughout the product interface:
```css
typography.family.sans: Inter
```

## Monospace Family
Used for code, technical identifiers, logs, developer tooling, and numerical data:
```css
typography.family.mono: JetBrains Mono
```

## Fallback Stack
```css
Inter,
system-ui,
-apple-system,
BlinkMacSystemFont,
"Segoe UI",
Roboto,
sans-serif
```

# 04 — Font Metrics

Two fonts can both be `16px` but appear completely different because of their metrics:
- **Cap Height**: Height of capital letters
- **X-Height**: Height of lowercase letters (determines perceived body text size)
- **Ascender & Descender**: Extension above cap height and below baseline
- **Line Gap**: Native breathing space
- **Glyph Width**: Monospace vs proportional rhythm

```
Font Size + Font Metrics + Line Height ──► Perceived Typography
```

# 05 — Font Weights

| Token | Numeric Value | Primary Role |
| :--- | :---: | :--- |

| `typography.weight.medium` | `500` | Interactive controls, form labels, table headers |
| `typography.weight.semibold` | `600` | Section headings, card titles, subheadings |

Controls vertical rhythm and reading fatigue:

| Token | Ratio | Primary Role |
| :--- | :---: | :--- |
| `typography.lineHeight.tight` | `1.2` | Display text and large headings |

| `typography.lineHeight.normal` | `1.5` | Standard paragraph body reading text |
| `typography.lineHeight.relaxed` | `1.7` | Editorial long-form reading |

# 11 — Text Behavior

Typography defines **how text behaves**, not just how it looks:

### Wrapping
Text naturally wraps (`wrap: true` / `whitespace-normal`) unless deliberately constrained.

### Truncation
- **Single-line**: `<Text truncate>` renders `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`
- **Multi-line**: `<Text truncate={2}>` clamps to 2 lines via `-webkit-line-clamp: 2;`

### Alignment (Logical Properties)
Uses logical alignment (`start`, `center`, `end`, `justify`) so layouts automatically adapt to RTL locales:
```css
text-align: start; /* Adapts to left in LTR, right in RTL */
```

# 12 — Accessibility & Semantic HTML

Visual styling is completely decoupled from document structure:
```tsx
// Renders an accessible <h2> while using text.heading.1 visual size
<Heading level={2} variant="heading-1">Dashboard Overview</Heading>
```
- **Text Scaling**: Components use `min-height` rather than fixed `height` to survive 200% text zoom.
- **Color Contrast**: 4.5:1 minimum contrast ratio for body text; 3:1 for large headings (WCAG 2.1 AA).
- **Reduced Motion**: Any kinetic typography animation respects `prefers-reduced-motion`.

---

# 13 — Numerals & Tabular Data

Tables, counters, statistics, and financial figures require fixed-width digits:
```css
.tabular-nums {
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum" 1, "cv02" 1;
}
```
Consumed cleanly via `<Text tabularNums>$124,500.00</Text>`.

# 14 — Figma Implementation

Figma variables mirror the code token structure:
- **Collections**: `Typography / Family`, `Typography / Weight`, `Typography / Size`, `Typography / Line Height`, `Typography / Letter Spacing`.
- **Text Styles**: `Text / Display`, `Text / Heading 1..4`, `Text / Body Large..Small`, `Text / Label Large..Small`, `Text / Caption`, `Text / Code`.
- **Rule**: Designers never introduce arbitrary sizes like `17px / 550`—components consume the established text styles.
