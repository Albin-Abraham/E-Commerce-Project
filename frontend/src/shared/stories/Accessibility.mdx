# Accessibility

The Zenith Design System is built with accessibility as a first-class concern. All components follow WCAG 2.1 AA guidelines and include comprehensive ARIA support.

## Accessibility Features

### Semantic HTML

All components use proper semantic HTML elements:

```tsx
// Buttons use <button> not <div>
<Button>Accessible Button</Button>

// Forms use proper <label> associations
<VStack gap="xs">
  <label htmlFor="email">Email</label>
  <input id="email" type="email" />
</VStack>

// Headings follow hierarchy
<Text variant="h1">Page Title</Text>
<Text variant="h2">Section Title</Text>
<Text variant="h3">Subsection</Text>
```

### ARIA Support

Components include appropriate ARIA attributes:

```tsx
// Modal includes proper ARIA
<Modal
  isOpen={true}
  onOpenChange={setOpen}
  aria-labelledby="modal-title"
  aria-describedby="modal-description"
>
  <Modal.Header>
    <Text id="modal-title" variant="h2">Dialog Title</Text>
  </Modal.Header>
  <Modal.Body>
    <Text id="modal-description">Dialog description</Text>
  </Modal.Body>
</Modal>

// AlertDialog has role="alertdialog"
<AlertDialog
  isOpen={true}
  onOpenChange={setOpen}
  title="Confirm Delete"
  message="This action cannot be undone."
/>

// Toast has role="status" or role="alert"
<ToastContainer />
```

### Focus Management

#### Focus Trapping

```tsx
import { FocusTrap } from "@zenith/design-system";

<FocusTrap active={isModalOpen}>
  <ModalContent />
</FocusTrap>
```

#### Focus Restoration

```tsx
// Modal automatically restores focus to trigger element
<Modal isOpen={isOpen} onOpenChange={setOpen}>
  <Modal.Header>Title</Modal.Header>
  <Modal.Body>Content</Modal.Body>
</Modal>

// FocusTrap restores focus on unmount
<FocusTrap active={true}>
  <DrawerContent />
</FocusTrap>
```

#### Skip Links

```tsx
// Add at top of page
<a href="#main-content" className="sr-only focus:not-sr-only focus:absolute focus:top-4 focus:left-4 z-50 px-4 py-2 bg-primary text-white rounded">
  Skip to main content
</a>

<main id="main-content">...</main>
```

### Keyboard Navigation

All interactive components support full keyboard navigation:

| Component | Keys |
|-----------|------|
| Button | `Enter`, `Space` |
| Link | `Enter` |
| Input | `Tab` to focus, type to edit |
| Select | `Enter`/`Space` to open, `Arrow` to navigate, `Enter` to select |
| Modal | `Esc` to close, `Tab` cycles within |
| Dropdown | `Enter`/`Space` to open, `Arrow` to navigate, `Esc` to close |
| Tabs | `Arrow` to switch, `Home`/`End` for first/last |
| Slider | `Arrow` to adjust, `Home`/`End` for min/max |
| Data Table | `Arrow` to navigate cells, `Enter` to sort |

### Color Contrast

All components meet WCAG 2.1 AA contrast ratios:

| Element | Ratio | Level |
|---------|-------|-------|
| Text (normal) | 4.5:1 | AA |
| Text (large ≥18px) | 3:1 | AA |
| UI Components | 3:1 | AA |
| Focus Indicators | 3:1 | AA |

### Screen Reader Support

#### Live Regions

```tsx
// Toast announcements
<ToastContainer /> {/* Automatically announces toasts */}

// Form validation
<VStack gap="xs">
  <label htmlFor="email">Email</label>
  <input
    id="email"
    type="email"
    aria-invalid={!!error}
    aria-describedby={error ? "email-error" : undefined}
  />
  {error && <span id="email-error" role="alert">{error}</span>}
</VStack>

// Loading states
<Button isLoading aria-busy="true">
  Loading...
</Button>
```

#### Descriptive Labels

```tsx
// Icon buttons need accessible labels
<Button aria-label="Close dialog" onClick={close}>
  <X size={20} />
</Button>

// Complex components
<Select
  label="Country"
  aria-label="Select your country"
  options={countries}
/>

// Form fields with help text
<VStack gap="xs">
  <label htmlFor="password">Password</label>
  <input
    id="password"
    type="password"
    aria-describedby="password-help"
  />
  <span id="password-help" className="text-sm text-muted">
    Must be at least 8 characters
  </span>
</VStack>
```

## Testing Accessibility

### Storybook a11y Addon

```bash
# Run accessibility tests in Storybook
pnpm test:a11y
```

### Automated Testing

```tsx
// jest + @axe-core/playwright
import { test, expect } from "@playwright/test";
import AxeBuilder from "@axe-core/playwright";

test("should not have accessibility violations", async ({ page }) => {
  await page.goto("/your-page");
  const accessibilityScanResults = await new AxeBuilder({ page }).analyze();
  expect(accessibilityScanResults.violations).toEqual([]);
});
```

### Manual Testing Checklist

- [ ] Navigate entire app with keyboard only
- [ ] Test with screen reader (NVDA, JAWS, VoiceOver)
- [ ] Verify focus indicators are visible
- [ ] Check color contrast ratios
- [ ] Test with zoom at 200%
- [ ] Verify skip links work
- [ ] Test form validation announcements
- [ ] Check modal focus trapping
- [ ] Verify error messages are announced

## Component-Specific Guidelines

### Buttons

```tsx
// Always use <button> for actions
<Button onClick={handleClick}>Submit</Button>

// Use variant for visual hierarchy
<Button variant="primary">Primary Action</Button>
<Button variant="secondary">Secondary Action</Button>
<Button variant="ghost">Tertiary Action</Button>

// Loading state
<Button isLoading>Processing...</Button>

// Disabled state
<Button disabled>Not Available</Button>
```

### Forms

```tsx
// Always associate labels
<VStack gap="xs">
  <label htmlFor="name">Name</label>
  <input id="name" />
</VStack>

// Group related fields
<fieldset>
  <legend>Contact Preference</legend>
  <label><input type="radio" name="contact" value="email" /> Email</label>
  <label><input type="radio" name="contact" value="phone" /> Phone</label>
</fieldset>

// Error handling
<VStack gap="xs">
  <label htmlFor="email">Email</label>
  <input
    id="email"
    type="email"
    aria-invalid="true"
    aria-describedby="email-error"
  />
  <span id="email-error" role="alert">Invalid email format</span>
</VStack>
```

### Modals

```tsx
// Proper modal structure
<Modal isOpen={isOpen} onOpenChange={setOpen}>
  <Modal.Header>
    <Modal.Close aria-label="Close dialog" />
  </Modal.Header>
  <Modal.Body>
    {/* Content */}
  </Modal.Body>
  <Modal.Footer>
    <Button variant="ghost" onClick={() => setOpen(false)}>Cancel</Button>
    <Button onClick={handleConfirm}>Confirm</Button>
  </Modal.Footer>
</Modal>
```

### Tables

```tsx
// Accessible table structure
<table>
  <caption>User Data</caption>
  <thead>
    <tr>
      <th scope="col">Name</th>
      <th scope="col">Email</th>
      <th scope="col">Role</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>John Doe</td>
      <td>john@example.com</td>
      <td>Admin</td>
    </tr>
  </tbody>
</table>
```

### Images

```tsx
// Decorative images
<img src="decoration.png" alt="" aria-hidden="true" />

// Informative images
<img src="chart.png" alt="Bar chart showing 20% increase in Q1" />

// Complex images
<img
  src="complex-diagram.png"
  alt="Flow diagram showing user authentication process"
  aria-describedby="diagram-desc"
/>
<div id="diagram-desc">
  Detailed description of the diagram...
</div>
```

## Common Patterns

### Accessible Card

```tsx
<article className="card">
  <img src="image.jpg" alt="Article thumbnail" />
  <div className="card-content">
    <h2><a href="/article">Article Title</a></h2>
    <p>Article excerpt...</p>
    <a href="/article" className="btn">Read More</a>
  </div>
</article>
```

### Accessible Navigation

```tsx
<nav aria-label="Main navigation">
  <ul>
    <li><a href="/home" aria-current="page">Home</a></li>
    <li><a href="/products">Products</a></li>
    <li>
      <a href="/about">About</a>
      <ul>
        <li><a href="/team">Team</a></li>
        <li><a href="/careers">Careers</a></li>
      </ul>
    </li>
  </ul>
</nav>
```

### Accessible Data Entry

```tsx
<form>
  <div className="field-group">
    <label for="username">Username</label>
    <input
      id="username"
      type="text"
      required
      aria-required="true"
      autocomplete="username"
    />
  </div>

  <div className="field-group">
    <label for="password">Password</label>
    <input
      id="password"
      type="password"
      required
      aria-required="true"
      autocomplete="current-password"
    />
  </div>

  <button type="submit">Sign In</button>
</form>
```
